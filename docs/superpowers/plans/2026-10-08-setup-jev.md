# Setup and JEV Implementation Plan

> **For agentic workers:** Use executing-plans inline, with TDD and one independent whole-branch review.

**Goal:** Ship reproducible interactive setup and optional typed decision tools in a reviewable PR.

**Architecture:** Validated declarative configuration feeds catalog resolution, platform rendering and transactional installation. CLI and MCP decision transports share a bounded TypeSafe HTTP client and versioned rubrics.

**Tech Stack:** Node.js >=20, TypeScript, node:test, native fetch/readline, jsonc-parser for preserving JSONC.

**Spec:** `docs/superpowers/specs/2026-10-08-interactive-setup-design.md` and `docs/superpowers/specs/2026-10-08-jev-decision-support-design.md`.

## Global Constraints

- Node.js >=20; support codex, opencode, claude and pi.
- No secrets in generated configuration; environment variable references only.
- No runtime installation, global package installation, login, merge or release publication.
- Dry-run has no project writes; conflicts prevent all installation writes.
- JEV is optional and never grants permissions or certifies acceptance.

## Review Focus

- Existing MCP config with unrelated user edits must be preserved.
- EOF, cancellation, malformed flags and non-TTY input must not hang or partially apply.
- Symlink paths and external skill resources must not escape installation/staging roots.
- Malformed API responses, redirects and timeouts must not leak keys or produce recommendations.
- Setup followed by skills add and update must preserve the resolved installation selection.
